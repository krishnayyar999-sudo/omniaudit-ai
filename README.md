# OmniAudit AI 🛡️
> Automated Code Security, Bug Detection & Big-O Complexity Inspector

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://omniaudit-ai.streamlit.app)

OmniAudit AI is an intelligent developer companion powered by Streamlit and Google's Gemini API. It inspects source code in real time (C++ and Python) to identify critical vulnerabilities, calculate algorithmic time/space complexity, and suggest refactored implementations.

## 🚀 Live Demo
- **Web Application:** [https://omniaudit-ai.streamlit.app](https://omniaudit-ai.streamlit.app)
- **Video Walkthrough:** [Watch on YouTube](https://youtu.be/clq4xCT2Wpk)

## ✨ Key Features
- **Security & Bug Audit:** Identifies memory leaks, buffer issues, unbound pointers, and logical edge cases.
- **Big-O Complexity:** Calculates Time and Space complexity with clear explanations.
- **Code Optimization:** Delivers cleaner, refactored replacement code.
- **Audit Export:** Generates downloadable timestamped audit reports (`.txt`).

## 🛠️ Tech Stack
- **Frontend / Framework:** Streamlit
- **LLM Engine:** Google Gemini API
- **Supported Languages:** C++, Python
